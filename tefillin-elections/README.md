# מבצע תפילין בקלפיות – מערכת שיבוץ

אתר לשיבוץ אנ״ש למבצע תפילין בקלפיות ביום הבחירות (יום שלישי, ט״ז בחשון).

**כתובת האתר:** https://shnotik770-netizen.github.io/my-links-app/tefillin/
**כניסת מנהל:** אותה כתובת + `#/admin` (או הקישור "כניסת מנהל" בתחתית העמוד)

## מה יש באתר

**למתנדבים (בלי הרשמה או כניסה):**
- באנר רץ בראש העמוד עם משפטי חיזוק
- עיצוב לפי מודעת הקמפיין: צהוב וכחול, גופן Secular One, משיחות מכחול, ותמונת רקע מהמודעה (`public/img/hero.webp`)
- הכותרת בעיצוב הריבוע מהמודעה ("בואו למבצע תפילין / בכל הקלפיות המובחרות בעיר / עפולה"), עם קלפי לבנה שפתק עם ש ו"בחרתי לעשות מבצעים" נכנס אליה והיא מתנדנדת
- חיפוש לפי שם קלפי או שם משובץ, כפתור "רק פנויות", וכפתורי מעבר מהיר לכל קלפי
- תצוגה "לפי קלפי" או "לפי שעה" (כרטיס לכל שעה עם כל הקלפיות שפעילות בה). הבחירה נשמרת במכשיר, וזמינה גם למנהל
- לכל קלפי: כתובת, ניווט בגוגל מפות ו-Waze (מדויק לפי נ.צ. אם הוזן), הערות, ומנהל קלפי עם כפתור וואטסאפ ישיר
- הסבר איך נרשמים בבועה מאחורי כפתור "?" (נפתחת לבד רק בכניסה הראשונה)
- משמרות של שעה בין 08:00 ל-18:00 (כברירת מחדל 09:00–13:00, המנהל מוסיף או מוריד שעות). לוחצים על משבצת פנויה, כותבים **שם מלא** (חובה) וטלפון (לא חובה), והשם נכנס ללוח
- עד 2 פעילים בכל שעה: הראשון נרשם במשבצת, ואחריו מופיע כפתור "+ הוסף פעיל"
- משבצת תפוסה מציגה את שמות המשובצים. הטלפונים שלהם גלויים רק למנהל
- שינוי או ביטול שיבוץ: פונים לאחד ממנהלי הקלפיות

**למנהל:**
- הוספה, עריכה ומחיקה של קלפיות: שם, כתובת, נ.צ. מגוגל מפות, הערות, שעות פעילות, ושם וטלפון של מנהל הקלפי
- "שעות לכל הקלפיות": הוספה או הסרה של שעת משמרת בכל הקלפיות בבת אחת
- צפייה בכל המשובצים עם טלפון, קישור חיוג וקישור וואטסאפ
- שיבוץ ידני, החלפת משובץ וביטול שיבוץ
- ⇄ ליד פעיל: העברה לשעה או קלפי אחרת, או "שיבוץ גם לשם" (נשאר גם במקום הנוכחי). רשימת השעות מראה כמה כבר משובצים בכל שעה
- 👤 ליד פעיל: הופך אותו למנהל הקלפי (השם והטלפון שלו נכנסים כמנהל)
- "📲 שליחת פרטי כניסה": פותח וואטסאפ למנהל הקלפי עם כתובת הניהול והסיסמה שבה נכנסתם
- עריכת משפטי הבאנר הרץ
- שינוי סיסמת המנהל

## איך זה בנוי

```
tefillin-elections/
├── public/                    ← האתר (HTML/CSS/JS רגיל, בלי build)
│   ├── index.html
│   ├── style.css
│   ├── config.js              ← כתובת ה-API
│   ├── api.js                 ← קריאות לשרת
│   └── app.js                 ← כל הממשק: מתנדבים + מנהל
├── supabase/
│   ├── schema.sql             ← מבנה מסד הנתונים (לעיון/שחזור)
│   └── functions/tefillin/    ← ה-Edge Function (השרת)
└── netlify.toml               ← אם תרצו לפרסם גם ב-Netlify
```

- **אחסון האתר:** GitHub Pages מהענף `main`. כל דחיפה ל-`main` מעדכנת את האתר תוך כדקה.
- **מסד נתונים:** Supabase, בפרויקט `toranim-system`, בטבלאות נפרדות עם הקידומת `tefillin_`.
- **אבטחה:** באתר אין שום מפתח של Supabase. הדפדפן מדבר רק עם ה-Edge Function `tefillin`, שמחזיקה את מפתח השרת ויכולה לגשת **רק** לטבלאות `tefillin_*`. לטבלאות האלה אין גישה ציבורית בכלל (RLS פעיל ואין הרשאות ל-anon). כך האתר הזה לא פותח שום גישה לנתוני התורנים.
- **סיסמת המנהל** שמורה במסד כ-hash (bcrypt) ולא מופיעה בקוד. משנים אותה מתוך מסך המנהל.

## צפייה בנתונים ישירות

ב-Supabase: פרויקט `toranim-system` ← Table Editor ← הטבלאות `tefillin_stations` ו-`tefillin_signups`. משם אפשר גם לייצא ל-CSV או לאקסל.

## עדכון השרת

אחרי שינוי ב-`supabase/functions/tefillin/index.ts` צריך לפרסם מחדש את הפונקציה (Supabase CLI: `supabase functions deploy tefillin --no-verify-jwt`), או לבקש מ-Claude.

## עדכון האתר

אחרי כל שינוי בקבצים שב-`public/` מריצים `./bump-version.sh` לפני הדחיפה ל-`main`. הסקריפט נותן לקבצים מספר גרסה חדש, כך שדפדפנים לא ימשיכו להשתמש בעותק ישן מהזיכרון. דף שכבר פתוח אצל מישהו יזהה שיש גרסה חדשה (דרך `version.json`) ויתרענן לבד.
