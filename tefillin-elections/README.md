# מבצע תפילין בקלפיות – מערכת שיבוץ

אתר לשיבוץ אנ״ש למבצע תפילין בקלפיות ביום הבחירות (יום שלישי, ט״ז בחשון).

**כתובת האתר:** https://shnotik770-netizen.github.io/my-links-app/tefillin/
**כניסת מנהל:** אותה כתובת + `#/admin` (או הקישור "כניסת מנהל" בתחתית העמוד)

## מה יש באתר

**למתנדבים (בלי הרשמה או כניסה):**
- באנר רץ בראש העמוד עם משפטי חיזוק
- חיפוש לפי שם קלפי או שם משובץ, כפתור "רק פנויות", וכפתורי מעבר מהיר לכל קלפי
- לכל קלפי: כתובת (קישור לניווט), הערות, ומנהל קלפי עם כפתור וואטסאפ ישיר
- שעות 09:00–13:00 במשבצות של שעה. לוחצים על משבצת פנויה, כותבים **שם מלא וטלפון** (חובה), והשם נכנס ללוח
- משבצת תפוסה מציגה את שם המשובץ. הטלפון של המשובץ גלוי רק למנהל
- שינוי או ביטול שיבוץ: רק דרך המנהל

**למנהל:**
- הוספה, עריכה ומחיקה של קלפיות: שם, כתובת, הערות, שעות פעילות, ושם וטלפון של מנהל הקלפי
- צפייה בכל המשובצים עם טלפון, קישור חיוג וקישור וואטסאפ
- שיבוץ ידני, החלפת משובץ וביטול שיבוץ
- עריכת משפטי הבאנר הרץ
- שינוי סיסמת המנהל

## איך זה בנוי

```
tefillin-elections/
├── public/                    ← האתר (HTML/CSS/JS רגיל, בלי build)
│   ├── index.html
│   ├── style.css
│   ├── config.js              ← כתובת ה-API
│   ├── api.js                 ← קריאות לשרת
│   └── app.js                 ← כל הממשק: מתנדבים + מנהל
├── supabase/
│   ├── schema.sql             ← מבנה מסד הנתונים (לעיון/שחזור)
│   └── functions/tefillin/    ← ה-Edge Function (השרת)
└── netlify.toml               ← אם תרצו לפרסם גם ב-Netlify
```

- **אחסון האתר:** GitHub Pages מהענף `main`. כל דחיפה ל-`main` מעדכנת את האתר תוך כדקה.
- **מסד נתונים:** Supabase, בפרויקט `toranim-system`, בטבלאות נפרדות עם הקידומת `tefillin_`.
- **אבטחה:** באתר אין שום מפתח של Supabase. הדפדפן מדבר רק עם ה-Edge Function `tefillin`, שמחזיקה את מפתח השרת ויכולה לגשת **רק** לטבלאות `tefillin_*`. לטבלאות האלה אין גישה ציבורית בכלל (RLS פעיל ואין הרשאות ל-anon). כך האתר הזה לא פותח שום גישה לנתוני התורנים.
- **סיסמת המנהל** שמורה במסד כ-hash (bcrypt) ולא מופיעה בקוד. משנים אותה מתוך מסך המנהל.

## צפייה בנתונים ישירות

ב-Supabase: פרויקט `toranim-system` ← Table Editor ← הטבלאות `tefillin_stations` ו-`tefillin_signups`. משם אפשר גם לייצא ל-CSV או לאקסל.

## עדכון השרת

אחרי שינוי ב-`supabase/functions/tefillin/index.ts` צריך לפרסם מחדש את הפונקציה (Supabase CLI: `supabase functions deploy tefillin --no-verify-jwt`), או לבקש מ-Claude.
